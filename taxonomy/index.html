P5 Sketches ~ Dependency Taxonomy

A browsable taxonomy of the dependencies that show up in p5.js sketches. Top-level categories start expanded; their sub-categories start collapsed. Click one to drill in or use the search box below to filter down to a dependency type.

We acknowledge that p5 offers different possibilities for generative art. However, the taxonomy below is focused on p5.js sketches that are displayed on a screen or projector. Therefore, physical computing aspects beyond the ones described below are not considered.
