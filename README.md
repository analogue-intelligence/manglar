> "Manglares (mangroves) are dense, hyper-interconnected root systems that protect and stabilize an entire ecosystem". In software engineering, we can think of a software project as a graph of interconnected components and dependencies.

## Project Structure
The project is structured as follows:
```aiignore
manglar/
├── js/
├── python/
├── taxonomy/
```

The `js` directory contains the JavaScript implementation to extract dependencies from JavaScript files.
The `python` directory contains the Python implementation to extract dependencies from HTML files.
The `taxonomy` directory contains the taxonomy of the dependencies.
