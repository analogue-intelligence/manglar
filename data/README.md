# Manglar

## /data/

The data folder includes:

- `github_metadata.json`: List of 3668 sketches annotated with the following data:
  - list of p5 libraries.
  - list of external artifacts.
  - number of lines of code.
  - last commit.
  - owner metadata: number of followers, locations, creation
  - repository metadata: number of stars, commits, pull requests, forks, watchers, is it a fork, github topics.
  - main contributor metadata: same as owner metadata.
